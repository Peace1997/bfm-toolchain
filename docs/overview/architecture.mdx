## 分层结构

```mermaid
flowchart TB
    subgraph L1["上层（不在本工具链范围）"]
        BRAIN["大脑：任务规划 / 语义理解"]
        PERC["感知前端：视觉 / 状态估计"]
    end

    subgraph L2["BFM 小脑工具链"]
        direction TB
        DATA["数据集模块<br/>采集 · 清洗 · 格式化"]
        TRAIN["后训练模块<br/>微调 · 强化学习 · 评测"]
        DEPLOY["部署模块<br/>导出 · 推理运行时"]
        DATA --> TRAIN --> DEPLOY
    end

    subgraph L3["本体"]
        CTRL["实时控制器：伺服环 · 安全保护"]
        HW["机器人硬件"]
        CTRL --> HW
    end

    BRAIN --> DEPLOY
    PERC --> DEPLOY
    DEPLOY --> CTRL
    HW -. "观测回传" .-> DEPLOY
    HW -. "录制轨迹" .-> DATA
```

## 一条技能的生命周期

```mermaid
flowchart LR
    A["01 采集<br/>遥操作演示"] --> B["02 处理<br/>清洗与对齐"]
    B --> C["03 后训练<br/>BFM 上微调"]
    C --> D["04 评测<br/>仿真回归"]
    D -->|不达标| C
    D -->|达标| E["05 部署<br/>仿真 → 真机"]
    E -.->|"补采失败场景"| A
```

注意两条回边：评测不达标要回到训练，真机上暴露的失败场景要回到采集。**这两条回边才是实际工作中花时间最多的地方**，文档会在对应章节展开。
