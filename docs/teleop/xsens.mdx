# Xsens 遥操作

基于 Xsens 动捕服的遥操方案。代码环境与 [PICO 方案](/docs/teleop/pico) 相同，先完成 [环境配置](/docs/teleop/setup)。

## 环境与启动

在完成通用环境配置、GMR 环境、手柄按键同步后：

```bash
# 配置 Xsens 环境
bash src/leju_launch/scripts/setup_xsens_gmr_env.sh

# 启动 Xsens 遥操程序
bash src/leju_launch/scripts/launch_xsens_real.sh
```

## 整体流程

1. 确认 Xsens 校准完成、推流关闭，演员保持起始姿态
2. 启动程序让机器人先站起来
3. 按游戏手柄 `start` 切到 AMP 控制器
4. 向机器人下位机发送 bvh 文件，打开 Xsens 推流
5. 按游戏手柄 `B` 开始遥操
6. 遥操结束后关闭 Xsens 推流

穿戴好动捕服后：

1. 按下动捕服右后侧腰部 hub 上的开关（按一次开机，连续按三次关机）
2. 打开 Xsens 上位机软件
3. 等待动捕服连接（关联系统显示硬件型号，右侧全部小绿点亮起）
4. 输入演员的**身高**和**脚长**

:::warning 身高与脚长要准确
脚长要算上鞋子的长度和高度。这两个数据直接影响校准质量。
:::

## 设备校准

点击左侧校准按钮，按提示进行。校准分两步：

1. 演员自然原地站立，**两脚自然分开**（不要双脚并拢）
2. 听到播报「行走」或界面显示「行走」时，自然向前走约 5~6 步，转身 180°，再走约 5~6 步，然后转身站好，站姿与第一步一致，等待校准完成

:::warning 校准要领
校准过程中演员应自然目视前方，不要左顾右盼，动作不要过度僵硬。**校准完成后若显示校准质量较差，需要重新校准。**
:::

校准姿势类型选择 **姿势 N（推荐）**。

## 录制数据包与导出 BVH

1. 校准完成后点击录制按钮开始录制
2. 再次点击结束录制并保存
3. 导出为 BVH：可打开刚录制的文件单个导出，也可不打开文件直接批量导出文件夹内全部文件

:::warning 重新标定后必须重新录包
每次重新标定后都需要重新录包转 bvh，**新的 bvh 才可以用于机器人遥操**。
:::

## 发送 BVH 与推流

:::danger 开始推流后动捕演员不要乱动
否则机器人切换至遥操模式后可能会失控。
:::

1. 运行 BVH 解析程序（<span className="badge-todo">待补充公开下载地址</span>）
2. 手动输入 bvh 文件路径，或把 bvh 文件拖拽到命令行中，回车
3. 输入机器人下位机 IP（默认端口号可不输入）
4. 发送 bvh 后开启网络流程序，开始向机器人推送动作流数据

网络流程序可从「文件」或「选项」菜单打开。配置要点：

- **仅勾选**「位置 + 方向（四个一组）」
- 上方修改为机器人的 IP 并勾选该行
- 端口号使用 `9763`

勾选后即可开始网络推流。

## 自组网模块

使用自组网模块通讯时需要两套模块：一套用于 Xsens → PC，一套用于 PC → 机器人。

:::warning 标有「机器人」的模块接数据接收端
标签写了「机器人」的模块要用于**数据接收端**而非发送端：

- Xsens → PC 这段，PC 是接收方，所以写着「机器人」的模块插到 PC 上
- PC → 机器人这段，机器人是接收方，写着「机器人」的模块插到机器人上
:::

自组网模块的电源开关在天线旁边。**使用后记得及时关机充电**，否则会导致遥操出现明显的延迟与断联问题（1 秒以上延迟）。
