# PICO 遥操作

先完成 [环境配置](/docs/teleop/setup)，再按本页操作。

## 1. PICO 校准

### 体感追踪器校准

1. 在资源库中打开 **PICO 体感追踪器**，点击立即校准
2. 按提示身体站直双手放于两侧，**双脚并拢紧贴**，目视前方；完成后按提示向下看体感追踪器
3. **校准地面**：若虚拟小人悬空，先向四周看，然后面朝前方、下蹲，用手柄轻触地面
4. **划定安全边界**：右上角选择「自定义安全边界」，按住右手扳机在周围划定

:::warning 遥操过程中不能出安全边界
:::

校准完成后观察虚拟形象的动作跟踪情况。**若出现小人悬空、或左右手/左右腿跟踪异常，需要重新校准。**

### 软件内校准

1. 模式选择**全身追踪**，右上角点击立即校准，流程与上一步完全相同
2. 校准后若**前方绿色方块小人全身变为绿色**则成功；**有灰色则重新校准**

:::note
按正确流程校准数次后方块小人脚仍为灰色，但 PICO 虚拟小人确认在地面上时，可以继续进行流程。

以上两步可在启动机器之前提前完成。**演员如果中途摘下头戴或足部追踪器，需要重新校准。**
:::

## 2. 启动遥操作

:::danger 务必完整准确完成前面所有步骤后再启动机器人
:::

```bash
export ROBOT_VERSION=17
sudo su
sudo bash src/leju_launch/scripts/launch_teleop_real.sh
```

:::warning 不要先 sudo su 再执行
不能 `sudo su` 之后再 `bash src/leju_launch/scripts/launch_teleop_real.sh`，否则会报 GMR `glGetError`。
:::

启动后：

1. 遥操作软件界面左侧**机器人服务器在线列表**选择分配的 IP（如 `10.42.0.1`），点击**连接**，再点击**遥操作**。此时左手手柄附近方块变绿并显示 ping 值；若为红色显示 error 则连接失败，检查网络
2. PICO 按 `右手上扳机 + B` 进行**重定向校准**（不校准无法进行后续步骤）。校准时需**两腿自然打开且竖直，双臂自然下垂，双眼目视前方，位于脚下蓝色方块中心且与蓝色方块朝向相同**（绿色方块人必须在演员正对面）
3. 北通手柄按 `start` 进入 AMP
4. PICO 手柄按 `侧扳机 + A` 开始全身遥操

:::warning 开始遥操前确认
测试人员在安全边界之内、机器人服务器正确连接、PICO 与重定向校准完成；保持身体直立，**膝盖略微弯曲**，双手垂直放于身体两侧。
:::

## 3. 动作要领

:::tip 小步中高频行走
- **前进后退**：步频保持正常行走步频，不能太慢，要有一定抬腿高度
- **停止**：从运动到静止不要突然停止，需要一段过渡，例如原地小步踏几下
- **转身**：不要一次转太多角度，每次 45 度以内
- **下蹲**：下蹲前要侧向跨一步，有助于保持机器人稳定
- **侧行**：过程中收腿不要过近
- **灵巧手抓取**：先按 `LG`/`RG` 内扣大拇指，再按 `RT`/`LT` 抓握，这样比较容易抓到
:::

## 4. 数据录制

开始遥操后，按 `LT + Y` 开始录制，`LT + X` 停止录制。

录制的数据保存在 `src/leju-controllers/leju-rl-controller/config/17/motion_data`，可直接作为离线轨迹播放。

:::warning 录制的两个前提
1. 只能在**遥操作开始后**录制，即按过 `RT + B` 和 `RG + A` 之后
2. 必须按 `LT + X` 停止录制才会保存，否则数据丢失
:::

录下来的数据可以直接进入 [整机数采训练](/docs/training/intro) 流程。

## 按键一览

### PICO 手柄

| 按键 | 说明 |
| --- | --- |
| `RG`（侧扳机）+ `A` | 切到 PICO HEFT 全身遥操 |
| `RG` + `B` | 切换回 AMP |
| `RT` + `Y` | 中断/暂停，机器人保持当前姿态不跟踪 |
| `RT` + `X` | 恢复跟踪（恢复时机器人与人体姿态差异不能过大） |
| `RT` + `B` | 上肢重定向校准 |
| `RT` / `LT` | 灵巧手抓握 |
| `RG` / `LG` | 灵巧手大拇指内扣 |
| `LT` + `Y` | 开始录制 |
| `LT` + `X` | 停止录制 |
| 长按右手 `o` 键 | 把蓝色方块移到操作人员脚下 |

:::warning 长按 o 键后必须重新校准
移动蓝色方块后要重新进行上肢重定向校准，**且禁止在开始遥操作后按**。
:::

### 北通手柄

| 按键 | 说明 |
| --- | --- |
| `start` | 机器人站立进入 AMP |
| `back` + `start` | 机器人退出应用 |

## 仿真验证

网络配置和 PICO 校准与真机相同，仿真一般用 docker 部署：

```bash
cd ~/Lejulab_ARM/docker
./run.sh
catkin build

export ROBOT_VERSION=17
source devel/setup.zsh

roslaunch leju_launch pico_teleop.launch \
  simulation:=true enable_iceoryx_shm:=false enable_viewer:=true
```

## 常见问题

### PICO 界面内找不到 IP

1. 看配网是否成功：终端 `ifconfig` 看有没有 `10.42.0.1`，没有则重新配网
2. 虚拟环境配置错误导致 GMR 启动失败：尝试直接启动 GMR 看是否报错

### `RG + A` 无法切换到在线遥操

1. 检查按键映射是否正确
2. 检查是否进行了 `RT + B` 上半身校准
3. 如果之前运行过 `Lejulab_ARM`，删除之前编译的 build 目录从头编译：

```bash
rm -rf build_cmake build devel installed

CC=gcc-11 CXX=g++-11 scripts/cmake_configure.sh --fast build_cmake \
    -DCMAKE_BUILD_TYPE=Release
CC=gcc-11 CXX=g++-11 scripts/cmake_build.sh build_cmake
```
