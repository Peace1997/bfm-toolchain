# 工具链是什么

**BFMTools** 是围绕 BFM（Behavior Foundation Model，行为基础模型）的一套工程工具，负责把一个技能从「一段人类示范」推到「机器人稳定执行」。

它覆盖三件事：

- **模型部署** —— 把策略导出、装进推理运行时，先在仿真跑通，再上真机。
- **数据集** —— 统一数据格式，规范采集与清洗，让不同人采的数据能混在一起训。
- **技能后训练** —— 在 BFM 预训练权重之上做微调或强化学习，长出新技能。

## 为什么叫「小脑」

沿用人脑的类比：**大脑**负责「做什么」——理解指令、拆解任务、规划步骤；**小脑**负责「怎么做」——把一个抽象动作变成几十个关节上的连续控制量，并在受到扰动时维持平衡。

这套工具链只管小脑这一层。它接收上层给的目标，输出关节级的控制指令，不做任务规划，也不做语义理解。

## 不做什么

明确一下边界，免得走错路：

- **不做任务级规划**。「去厨房拿杯子」这种指令的拆解不在这里。
- **不做感知前端**。视觉检测、SLAM、点云处理由上游模块提供，工具链只消费其输出。
- **不替代底层控制器**。关节级的伺服环、力矩安全保护仍在实时控制器里，工具链输出的是它的参考输入。
