# 基模介绍

**通用运控基模**是一个模型覆盖多种动作的全身运控底座。基于 BFM（Behavior Foundation Model，行为基础模型）构建，目标是让全身运控**开箱即用**，降低动作开发门槛。

## 和传统运动控制的区别

| | 传统方法（MPC / 手工步态） | 通用运控基模 |
| --- | --- | --- |
| 新动作成本 | 重新建模、重新调参 | 从动作库调用，或少量后训练 |
| 泛化能力 | 依赖模型精度，出域即失效 | 依赖数据覆盖，可增量补数据 |
| 可解释性 | 高，每项都能追到物理量 | 低，主要靠评测验证 |
| 实时性 | 可能受在线优化拖累 | 前向推理，耗时稳定 |
| 调试手段 | 看物理量 | 看数据与评测指标 |

不是替代关系。底层的伺服环和安全保护仍然是传统控制，基模替换的是上面那层「怎么动」的决策。

## 使用前请先明确

**基模不是通用机器人大脑。** 它不理解语言指令，也不做任务规划。它接收结构化的目标输入，输出关节级控制量。

**能力边界由数据决定。** 预训练数据没覆盖到的形态、负载、地形都可能失效。上真机前务必确认 [能力与边界](/docs/bfm/capabilities)。

**换本体不是免费的。** 关节构型不同，观测和动作空间就不同，跨本体使用需要额外适配。
