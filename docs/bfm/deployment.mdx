# 离线轨迹追踪部署

把一条离线轨迹交给基模播放出来。流程是：转换轨迹格式 → 配置环境 → 启动机器 → 手柄播放。

:::danger 务必先在仿真里验证
测试任何新轨迹之前**必须先在仿真中跑一遍**，确认没问题再上真机。
:::

## 部署流程

### 1. 转换轨迹格式

用转换脚本把 sonic csv 格式转成 heft csv 格式（脚本内有使用方法，缺包 `pip install` 即可）。

<Stub>

- `convert_sonic_csv_to_heft.py` 目前是飞书附件，需要放进开源仓库或补上下载地址

</Stub>

### 2. 克隆与编译

克隆仓库，切换到对应分支及提交，按 README 配置环境并编译。

:::warning 切分支要重新编译
每次切换分支都需要重新编译。
:::

### 3. 同步按键

否则手柄按键无法切换。

```bash
bash scripts/install_teleop_bindings.sh --overwrite
```

### 4. 放置轨迹与策略

把要测试的轨迹及策略放到对应路径中（`onnx` 和 `onnx.data` 放到相同路径），确认**参考数据观测未来帧及观测维度与配置文件一致**。

### 5. 启动机器

```bash
sudo su
export ROBOT_VERSION=17
sudo bash src/leju_launch/scripts/launch_real.sh
```

### 6. 播放轨迹

启动后用北通手柄操作：

| 操作 | 效果 |
| --- | --- |
| `start` | 切到 AMP |
| `A` | 切到 HEFT，播放第一条轨迹 |
| 再按 `A` | 播放下一条，循环播放 |

:::warning 轨迹之间目前无插值
选取的轨迹**开始和结束必须为向前静止站立**，否则请一次只测试一条，测第二条时重新启动机器。
:::

## 注意事项

**机型差异** —— 目前测试机型均为 `roban 2.2-72`，没有在多机上测试，效果可能有差异。

**环境影响** —— 不同环境或者地面对策略表现有影响。

**清理旧编译** —— 如果之前运行过 `lejulab_platform` 仓库，需要删除之前编译的 build 目录，从头配置并编译：

```bash
# 清理旧构建
rm -rf build_cmake
rm -rf build devel
rm -rf installed

# 配置（必须用 gcc-11）
CC=gcc-11 CXX=g++-11 scripts/cmake_configure.sh --fast build_cmake \
    -DCMAKE_BUILD_TYPE=Release

# 全量编译
CC=gcc-11 CXX=g++-11 scripts/cmake_build.sh build_cmake
```
