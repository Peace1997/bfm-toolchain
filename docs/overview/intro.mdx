## BFM 是什么

**BFM**（Behavior Foundation Model，行为基础模型）是这套工具链的底座。

它和「一个训好的策略」不是一回事。策略只会做一件事；BFM 在大规模行为数据上预训练，学到的是一整个**行为空间**——需要一个新动作时，不是从零训练，而是从这个空间里把它调出来。

这带来两个直接结果：

- **基础动作开箱即用**。行走、转身、连续动作这类能力已经在基模里，调用即可，不必逐个建模调参。
- **新技能的成本从「重新训练」降到「少量后训练」**。准备一批遥操示范数据，走一遍四步流程就能产出可用的操作技能模型。
