# 离线轨迹追踪部署

把一条离线轨迹交给基模播放出来。先完成 [环境配置](/docs/bfm/setup)。

:::danger 务必先在仿真里验证
测试任何新轨迹之前**必须先在仿真中跑一遍**，确认没问题再上真机。
:::

## 部署流程

### 1. 放置轨迹与策略

把要测试的轨迹及策略放到对应路径中，确认**参考数据观测未来帧及观测维度与配置文件一致**。

### 2. 启动机器

```bash
sudo su
export ROBOT_VERSION=17
sudo bash src/leju_launch/scripts/launch_real.sh
```

### 3. 播放轨迹

启动后用北通手柄操作：

| 操作 | 效果 |
| --- | --- |
| `start` | 切到 AMP |
| `A` | 切到 HEFT，播放第一条轨迹 |
| 再按 `A` | 播放下一条，循环播放 |

:::warning 轨迹之间目前无插值
选取的轨迹**开始和结束必须为向前静止站立**，否则请一次只测试一条，测第二条时重新启动机器。
:::

## 仿真验证

仿真中一般用 docker 启动：

```bash
cd ~/Lejulab_ARM/docker
./run.sh
catkin build
source devel/setup.zsh
export ROBOT_VERSION=17
roslaunch leju_launch load_mujoco_sim.launch enable_iceoryx_shm:=false
```

已在仿真中验证过的动作类型：拳击、舞蹈、爬行、空翻。

## 注意事项

**机型差异** —— 目前测试机型均为 `roban 2.2-72`，没有在多机上测试，效果可能有差异。

**环境影响** —— 不同环境或者地面对策略表现有影响。

**编译残留** —— 换过分支或之前编译过其他版本时，按 [环境配置 · 清理旧编译](/docs/bfm/setup#清理旧编译) 从头来一遍。
