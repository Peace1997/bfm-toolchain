# 数据格式

统一格式的意义：**不同人、不同时间、不同设备采的数据，能直接混在一起训练。**

这一页是数据侧的唯一真源。采集脚本、清洗工具、训练加载器都必须与它一致。

<Stub>

- 确定存储格式（HDF5 / Zarr / LeRobot Dataset / 自定义）
- 填写字段表的完整内容：字段名、dtype、shape、单位、坐标系
- 明确图像/深度等大字段的编码与压缩方式
- 定义版本号字段，以及格式升级时的迁移策略

</Stub>

## 目录布局

```text
<dataset_name>/
├── meta.json           # 数据集级元信息
├── episodes/
│   ├── 000000.<ext>    # 单条轨迹
│   ├── 000001.<ext>
│   └── ...
└── stats.json          # 归一化统计量（均值/方差/分位数）
```

## 数据集元信息 `meta.json`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `format_version` | string | 格式版本号，用于兼容性判断 |
| `embodiment` | string | 采集所用本体标识 |
| `control_freq` | float | 控制频率（Hz） |
| `episodes` | int | 轨迹条数 |
| `total_steps` | int | 总时间步数 |

## 单条轨迹

一条轨迹是一段等间隔采样的时间序列，长度记为 `T`。

### 观测字段

| 字段 | shape | dtype | 单位 | 说明 |
| --- | --- | --- | --- | --- |
| `obs/joint_pos` | `(T, N)` | float32 | rad | 关节位置 |
| `obs/joint_vel` | `(T, N)` | float32 | rad/s | 关节速度 |
| `obs/imu` | `(T, ?)` | float32 | — | <span className="badge-todo">字段构成待确认</span> |
| | | | | <span className="badge-todo">待补充</span> |

### 动作字段

| 字段 | shape | dtype | 单位 | 说明 |
| --- | --- | --- | --- | --- |
| `action` | `(T, M)` | float32 | — | <span className="badge-todo">含义待确认：目标位置？增量？</span> |

### 其他

| 字段 | shape | 说明 |
| --- | --- | --- |
| `timestamp` | `(T,)` | 单调递增时间戳（秒） |
| `done` | `(T,)` | 轨迹结束标记 |
| | | <span className="badge-todo">待补充语言指令、任务标签等</span> |

:::warning 关节顺序
`N` 个关节的**排列顺序**必须与 [基模动作库](/docs/bfm/action-library) 中的定义一致。顺序错了训练不会报错，但策略上机会直接出问题。
:::
