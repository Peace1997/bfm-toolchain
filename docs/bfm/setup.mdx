## 克隆与编译

克隆仓库，切换到对应分支及提交，按 README 配置环境并编译。

:::warning 切分支要重新编译
每次切换分支都需要重新编译。
:::

## 同步按键

不同步的话手柄按键无法切换。

```bash
bash scripts/install_teleop_bindings.sh --overwrite
```

## 配置文件要确认的字段

配置文件里有几个关键字段，**放置轨迹与策略后必须核对**：

- 策略路径
- 轨迹名称及路径
- 参考数据观测未来帧
- 观测维度

## 清理旧编译

如果之前运行过 `lejulab_platform` 仓库，需要删除之前编译的 build 目录，从头配置并编译：

```bash
# 清理旧构建
rm -rf build_cmake
rm -rf build devel
rm -rf installed

# 配置（必须用 gcc-11）
CC=gcc-11 CXX=g++-11 scripts/cmake_configure.sh --fast build_cmake \
    -DCMAKE_BUILD_TYPE=Release

# 全量编译
CC=gcc-11 CXX=g++-11 scripts/cmake_build.sh build_cmake
```
